# 简易快递柜控制器｜STM32课程设计
> 项目：大一嵌入式课程设计，基于STM32F103C8T6

## 功能简介
1. 矩阵按键输入密码
2. OLED屏幕显示提示信息
3. 串口USART通信
4. 定时器TIM任务调度
5. I2C驱动OLED显示屏

## 开发环境
- STM32CubeMX 图形化配置
- Keil MDK5
- HAL库开发

## 工程说明
- Core：应用源码
- Drivers：HAL驱动库
- MDK-ARM：Keil工程文件
- Simpleness.ioc：CubeMX工程配置文件
